# درخت حساب ها (Next.js + MUI + TypeScript)

    npm install
    npm run dev

سپس http://localhost:3000 را باز کنید.

- کلیک روی هر نود: باز/بسته کردن زیرشاخه ها
- کلیک راست: برش (فقط نود بدون فرزند)، کپی (همراه همه فرزندان)، پیست (به عنوان زیرشاخه)، حذف (فقط نود بدون فرزند)، افزودن زیرشاخه (مدال با ورودی عنوان)
